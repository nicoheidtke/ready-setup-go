# Security policy

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/nicoheidtke/ready-setup-go/security/advisories/new). Include the affected bundled action SHA, platform, impact, and a minimal reproduction. Keep exploit details, credentials, and private source out of public issues and pull requests.

## Supported versions

Security fixes target the latest published bundled prerelease. There is no stable or long-term support line, and no backport or response-time commitment. Fixes are delivered in a new distribution revision; SHA-pinned consumers must update explicitly.

See the [support and validation limits](docs/DEVELOPMENT.md#support-and-validation-status) for platform coverage and the [security model](docs/SECURITY_MODEL.md) for permissions, cache trust, persistent runners, and diagnostic privacy.
